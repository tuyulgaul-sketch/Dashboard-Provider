# Dashboard Provider — Managed Care Prototype\n\nPrototype portal operasional Managed Care PertaLife untuk sisi Provider dan Call Center PertaLife 24/7.\n\nTahap ini menggunakan mock/local data, tanpa Supabase atau database production.\n\n## Flow\n1. Admission / registration + eligibility check\n2. PertaLife verification\n3. Treatment / medication confirmation\n4. PertaLife verification\n5. Discharge verification\n6. Case closed\n\nGunakan Account Switcher di kanan atas untuk berpindah role tanpa login/logout.\n\n## Run\n`npm install` lalu `npm run dev`\n
